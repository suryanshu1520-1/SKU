## 1. Zero-Hallucination Grounding Protocol

### 1.1 Philosophy & Academic Austerity
In high-stakes competitive examinations (UPSC CSE, State PSCs), hallucinated current affairs summaries or ungrounded claims can cost an aspirant their attempt. Tark enforces an immutable, sentence-level verification protocol where every factual proposition generated by AI must trace back directly to an indexed, authoritative primary source (PIB, Gazette of India, The Hindu, PRS Legislative Research, or RBI).

### 1.2 Mathematical Formulation
Every intelligence dispatch generated by Tark is assigned a mathematically verifiable Grounding Score:

$$\text{Grounding Score} = \left( \frac{\sum_{i=1}^{N} \mathbf{1}\left(\text{Claim}_i \in \mathcal{C}_{\text{primary}}\right)}{N} \right) \times 100\%$$

Where:
* $N$ is the total number of factual propositions extracted from the AI summary.
* $\mathcal{C}_{\text{primary}}$ is the verbatim normalized corpus of the primary document.
* $\mathbf{1}(\cdot)$ is the binary verification indicator function (returns $1$ if the proposition has high-confidence semantic and lexical support in the primary source, $0$ otherwise).

### 1.3 4-Stage Verification Pipeline

```
┌─────────────────┐     ┌──────────────────────┐     ┌─────────────────────┐     ┌──────────────────────┐
│ 1. First-Source │ ──> │ 2. Atomic Claim      │ ──> │ 3. Semantic         │ ──> │ 4. Sentence Evidence │
│ Ingestion       │     │ Extraction           │     │ Cross-Validation    │     │ Ledger & Badging     │
└─────────────────┘     └──────────────────────┘     └─────────────────────┘     └──────────────────────┘
  • PIB & Gazette         • NLP proposition split      • Direct lexical match      • Verified badge (≥90%)
  • The Hindu & PRS       • Numerical checks           • Embedding cosine check    • Contested badge (<90%)
  • Raw archive stored    • Entity binding             • Source attribution        • Interactive audit UI
```

1. **First-Source Ingestion**: Raw text and metadata are scraped and archived without LLM paraphrasing.
2. **Atomic Claim Extraction**: Synthesized bullet points are decomposed into atomic, testable claims (dates, monetary amounts, ministry allocations, statutory sections).
3. **Semantic Cross-Validation**: Each atomic claim is evaluated against the primary text using dual lexical-overlap and semantic cosine matching.
4. **Sentence Evidence Ledger**: Sentences are color-coded in the UI. Users can click any citation pill `[©]` to reveal the exact excerpt from the source document.

### 1.4 Frontend Integration
* **`GroundingExplainerModal.tsx`**: 4-tab interactive modal (`Formula & Math`, `4-Stage Pipeline`, `Interactive Demo`, `Strict Safety Rules`) triggered via `[ 🛡️ How Grounding Works ]` or by clicking any `GroundingBadge`.
* **`GroundingBadge.tsx`**: Pill badge displaying grounding percentage with real-time color tokens:
  * **$\ge 90\%$**: Emerald (`#10b981`), `Verified First-Source`.
  * **$70\% - 89\%$**: Amber (`#f59e0b`), `Partially Grounded`.
  * **$< 70\%$**: Rose/Red (`#ef4444`), `Contested Claim (Audit Required)`.

## 2. Interactive Spotlight Tour Engine

### 2.1 Spatial Architecture & Glassmorphic Mask
To introduce new candidates to the Command Deck and Testing Arena without disruptive modal popups, Tark implements an SVG-masked spotlight tour engine in [`src/components/WebsiteTour.tsx`](file:///c:/Users/bentn/OneDrive/Desktop/SKU/src/components/WebsiteTour.tsx).

```xml
<svg className="absolute inset-0 w-full h-full pointer-events-none">
  <defs>
    <mask id="tour-spotlight-mask">
      <rect x="0" y="0" width="100%" height="100%" fill="white" />
      <!-- Dynamic cutout with rounded corners over target element -->
      <rect x={target.x - 8} y={target.y - 8} width={target.width + 16} height={target.height + 16} rx="6" fill="black" />
    </mask>
  </defs>
  <rect x="0" y="0" width="100%" height="100%" fill="rgba(3, 15, 33, 0.85)" mask="url(#tour-spotlight-mask)" />
</svg>
```

### 2.2 Tour Checkpoints

| Step | Tour Identifier | Feature | Target UI |
|---|---|---|---|
| 1 | `nav-brand` | Command Deck | War Room title & active candidate telemetry |
| 2 | `nav-tracker` | The Daily Brief | Autonomous Gazette & high-yield news wire |
| 3 | `grounding-info` | Zero-Hallucination Engine | Mathematical proof & sentence verification |
| 4 | `nav-arena` | Live Test Arena | Standard UPSC prelims simulation & timing rules |
| 5 | `nav-observatory` | PYQ Intelligence Vault | 25-year trend maps & examiner psyche analytics |
| 6 | `candidate-track` | Candidate Countdown | Time remaining to Prelims 2026 battle |

### 2.3 UX Controls & Ergonomics
* **Keyboard Navigation**: `ArrowRight` (Next), `ArrowLeft` (Previous), `Escape` (Skip/Dismiss).
* **Auto-Tab Switching**: The engine automatically executes `onNavigateTab()` when transitioning between different application modules.
* **Persistent Launchers**: Re-launchable at any time via `🧭 Product Tour` in the left vertical command rail and top navigation bar.
