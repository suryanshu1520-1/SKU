# Database Schema Reference — Tark 1.0

## 1. Entity-Relationship Overview

```
       ┌────────────────────────┐
       │   auth.users (Supabase)│
       └───────────┬────────────┘
                   │ 1:1
                   ▼
       ┌────────────────────────┐
       │        profiles        │
       └───────────┬────────────┘
                   │
         ┌─────────┼─────────────────────────┐
         │ 1:N     │ 1:N                     │ 1:N
```

## 2. Core Tables

### `profiles`
- **`id`** (`uuid`, PK): Foreign key to `auth.users.id`.
- **`email`** (`text`): User email address.
- **`username`** (`text`): Display name.
- **`tier`** (`text`, default `'free'`): Subscription tier (`'free'` | `'pro'`).
- **`xp`** (`int4`, default `0`): Total earned experience points.
- **`streak`** (`int4`, default `0`): Consecutive active quiz days.
- **`last_active_at`** (`timestamptz`): Timestamp of last recorded user action.

### `questions`
- **`id`** (`uuid`, PK): Unique question identifier.
- **`date`** (`date`): Scheduled date for the daily question.
- **`question`** (`text`): Question stem.
- **`options`** (`jsonb`): Array of multiple-choice option strings.
- **`correct_index`** (`int2`): Index of the correct option (0-indexed).
- **`explanation`** (`text`): Detailed explanation and background analysis.
- **`ministry`** (`text`): Associated government ministry / topic.
- **`source_url`** (`text`): Link to the original press release or gazette.

### `pib_digests`
- **`id`** (`uuid`, PK): Digest record identifier.
- **`date`** (`date`): Publication date.
- **`title`** (`text`): Synthesized headline.
- **`summary`** (`text`): Executive summary.
- **`markdown_content`** (`text`): Full formatted markdown article.
- **`tags`** (`text[]`): Categorical labels (e.g. `['Governance', 'Economy']`).
- **`source_urls`** (`text[]`): Source citations.

### `quiz_sessions` (Competitive)
- **`id`** (`uuid`, PK): Session record identifier.
- **`user_id`** (`uuid`, FK → `profiles.id`): Quiz participant.
- **`date`** (`date`): Daily quiz date.
- **`score`** (`numeric`): Calculated competitive score (+2 correct, -0.66 wrong).
- **`total_questions`** (`int4`): Total number of questions presented.
- **`correct_count`** (`int4`): Number of correct answers.
- **`incorrect_count`** (`int4`): Number of incorrect answers.
- **`answers`** (`jsonb`): User-submitted options mapping (`{ question_id: option_index }`).
- **`created_at`** (`timestamptz`): Session completion timestamp.

### `training_sessions` (Practice / Unranked)
- **`id`** (`uuid`, PK): Practice session identifier.
- **`user_id`** (`uuid`, FK → `profiles.id`): Participant.
- **`date`** (`date`): Practice date.
- **`score`** (`numeric`): Unranked practice score.
- **`correct_count`** (`int4`): Correct count.
- **`incorrect_count`** (`int4`): Incorrect count.
- **`answers`** (`jsonb`): Answers mapping.
- **`created_at`** (`timestamptz`): Timestamp.

### `pending_orders` (Concurrency & Seat Locks)
- **`id`** (`uuid`, PK): Order lock record.
- **`user_id`** (`uuid`, FK → `profiles.id`): Purchasing user.
- **`razorpay_order_id`** (`text`, unique): Order ID generated by Razorpay.
- **`amount`** (`int4`): Order amount in paise.
- **`status`** (`text`): `'pending'` | `'paid'` | `'expired'`.
- **`expires_at`** (`timestamptz`): Seat lock expiration (created_at + 15 minutes).

## 3. Row-Level Security (RLS) Policies

1. **Profiles**: Public read for leaderboard display; update allowed only where `auth.uid() = id`.
2. **Questions**: Public read-only; mutations restricted to `service_role`.
3. **PIB Digests**: Public read-only; mutations restricted to `service_role`.
4. **Quiz Sessions**: Users can insert and select only their own records (`auth.uid() = user_id`).
5. **Pending Orders**: Users can select and insert only their own order records.
