# Objects Shelf Contract

## Shelf Purpose

Houses cards for every domain noun (data models, state schemas, core entities) in Tark 1.0.

## Card Requirements

Each object card must follow `map/_templates/object.md`:
1. One-sentence definition (code vs product name).
2. Why this shape exists (load-bearing rationale).
3. Shape & schema citations (`file:line`).
4. Connected entities (owns / owned-by / joins).
5. First-order change impact (**Hits** / **Does not hit**).
6. Surfaces (readers and writers).
7. Source links.
