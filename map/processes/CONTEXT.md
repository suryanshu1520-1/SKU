# Processes Shelf Contract

## Shelf Purpose

Houses cards for the verified system movements (verbs and end-to-end transaction flows) in Tark 1.0.

## Card Requirements

Each process card must follow `map/_templates/process.md`:
1. One-sentence summary of the workflow.
2. Inputs, Movement steps with source citations (`file:line`), and Outputs.
3. Consumed / Produced object cards.
4. First-order change impact (**Hits** / **Does not hit**).
